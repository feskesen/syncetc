# 0113-A Customer-Side Aircraft / Asset Admin Foundation

## Purpose

Builds the first customer/organization-side Aircraft Admin foundation before maintenance squawks, reminders, scheduler, or billing are built.

This is not a SyncEtc platform-admin-only page. It is intended for organization/customer admins managing their own aircraft/assets. Platform admins may access it only through customer context/support workflows.

## What this includes

- Customer/organization admin aircraft page.
- Backend remains generic operational assets where possible.
- Aviation UI says Aircraft.
- Organization locations/bases.
- Aircraft identity fields: tail number, preferred/display name, year, make, model, ICAO type code, serial number.
- Classification fields: category/class, engine count, seats, fuel type/burn, equipment/features/checkouts.
- Operational fields: base, status, visibility, do-not-dispatch, dispatch note.
- Usage/rate groundwork: Hobbs/Tach/airframe fields, billing basis, hourly rate, annual due, fuel included, tax behavior.
- Media/description placeholders: primary image URL, panel image URL, summary, long description, internal notes placeholder.
- Maintenance setup placeholder section only; squawks/reminders are not built here.
- Search/filter list, New Aircraft, Save, Clear, Archive/Restore.
- Bases & Locations editor.
- Slug/SKU is generated by backend and not user editable.
- Nav-away protection for unsaved changes.

## Not included

- Scheduler/reservations.
- Maintenance squawk/discrepancy system.
- Full reminder/AD/inspection system.
- Full billing/finance/rate matrix.
- Member-facing aircraft editor.
- Page registry cleanup.
